# Сброс пароля

Пароль от корпоративной учетной записи можно сбросить через страницу account.company.local/reset.

Для сброса потребуется код из приложения двухфакторной аутентификации. Если приложение недоступно, нужно создать заявку в IT Service Desk и приложить фото пропуска.

После сброса пароля все активные сессии завершаются. Новый пароль должен содержать не менее 14 символов, буквы в разных регистрах, цифру и специальный символ.

Повторное использование последних пяти паролей запрещено политикой безопасности.
