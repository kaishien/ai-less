# Информационная безопасность

Корпоративные документы нельзя пересылать на личную почту или загружать в публичные файловые хранилища.

Файлы с персональными данными должны храниться только в корпоративном облаке с ограниченным доступом по рабочим группам.

Подозрительные письма нужно пересылать на security.company.local/report или отмечать кнопкой "Фишинг" в почтовом клиенте.

Сотрудник обязан немедленно сообщить в службу безопасности, если потерял ноутбук, токен доступа или корпоративный телефон.
