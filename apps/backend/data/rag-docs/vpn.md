# VPN

Для подключения к корпоративному VPN сотрудник должен установить клиент WireGuard из внутреннего портала и импортировать персональный профиль.

Профиль доступен в разделе "Безопасность -> VPN". После импорта нужно включить туннель и проверить доступ к адресу intranet.company.local.

Если профиль не открывается или подключение не устанавливается, сотрудник должен сбросить профиль в портале и создать новый. Старый профиль автоматически отзывается.

VPN обязателен для доступа к внутренним сервисам из публичных сетей, включая домашний Wi-Fi, аэропорты и коворкинги.
