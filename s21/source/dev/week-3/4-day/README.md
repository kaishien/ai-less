### 📋 Регламент демо

**10 минут на команду, строго:**

| Время | Что показывают |
|---|---|
| 0–1 мин | `docker-compose up` (или уже запущено) + `curl /health` |
| 1–3 мин | Live-запрос с высокой уверенностью → агент отвечает с источниками |
| 3–5 мин | Live-запрос с HITL → interrupt → resume → финальный ответ |
| 5–7 мин | LangSmith trace: токены, latency, узлы |
| 7–9 мин | Mermaid-схема: объясните 2–3 архитектурных решения |
| 9–10 мин | Вопросы |

Следите за временем — при нарушении регламента мягко прерываете.

### 💬 Вопросы для разбора после демо

Задавайте 1–2 вопроса из списка, адаптируя к конкретному проекту:

**Архитектурные:**
- Почему выбрали именно это количество узлов?
- Как state передаётся между hybrid_search и rerank?
- Что произойдёт если Qdrant вернёт 0 результатов?

**Надёжность:**
- Как обработан RateLimitError?
- Что происходит при перезапуске контейнера — теряется ли состояние сессии?

**Практические:**
- Как бы изменили архитектуру, если бы документов стало в 100 раз больше?
- Что узнали о поведении LLM из LangSmith трейсов?
