# Команда: /review

## Описание
Проведи детальное code review Python кода.

## Prompt
Проанализируй этот код и проверь:

1. **Безопасность:**
   - SQL injection (параметризованные запросы / ORM?)
   - Валидация пользовательских данных (Pydantic)
   - Хранение секретов (env vars, не в коде)
   - Хеширование паролей

2. **Производительность:**
   - Неоптимальные алгоритмы (O(n²))
   - N+1 проблемы в запросах
   - Sync I/O в async коде (блокировка event loop)
   - Memory leaks (незакрытые соединения)

3. **Читаемость:**
   - Понятные имена переменных/функций
   - Single Responsibility
   - Избыточная сложность

4. **Обработка ошибок:**
   - Try/except для I/O операций
   - Не "глотается" ли ошибка молча
   - Валидация входных данных
   - Логирование ошибок

5. **Типизация (mypy):**
   - Отсутствие `Any`
   - Правильные type hints
   - Использование dataclass / Pydantic

**Результат:**
Список найденных проблем с приоритетом:
- 🔴 Критично (требует немедленного исправления)
- 🟡 Важно (исправить в ближайшее время)
- 🟢 Рекомендация (улучшение)

И примеры исправлений для каждой проблемы.
