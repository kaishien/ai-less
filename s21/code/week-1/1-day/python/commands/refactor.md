# Команда: /refactor

## Описание
Рефактори Python код для улучшения читаемости и поддерживаемости.

## Prompt
Отрефактори этот код согласно Python best practices:

1. **Clean Code принципы:**
   - **Single Responsibility:** каждая функция делает одно
   - **DRY:** устрани дублирование
   - **Понятные имена:** переименуй неясные переменные/функции
   - **Магические числа:** замени на именованные константы

2. **Python идиомы:**
   ```python
   # ❌ ПЛОХО
   result = []
   for item in items:
       if item.active:
           result.append(item.name)

   # ✅ ХОРОШО
   result = [item.name for item in items if item.active]
   ```

3. **Типизация:**
   - Добавь type hints везде где их нет
   - Замени `dict` на `TypedDict` или `dataclass`
   - Используй `str | None` вместо `Optional[str]`
   - Исправь `Any` на конкретные типы

4. **Структуры данных:**
   - Используй `set` для проверки наличия (O(1) vs O(n))
   - Используй `dict` для маппингов вместо if/elif цепочек
   - `dataclass` / `namedtuple` вместо tuple с индексами

5. **Разделение логики:**
   - Выдели бизнес-логику в сервисы
   - Отдели валидацию (Pydantic) от обработки
   - Создавай utility функции для повторяющихся операций

6. **Async:**
   - Заменяй sync I/O на async (requests → httpx, psycopg2 → asyncpg)
   - Используй `asyncio.gather` для параллельных операций

**Результат:**
Отрефакторенный код с объяснением каждого изменения и почему это улучшение.
