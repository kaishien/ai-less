# Команда: /security

## Описание
Проверь Python код на уязвимости безопасности.

## Prompt
Проведи security audit этого кода:

1. **Injection атаки:**
   - ✅ SQL Injection: используются ли параметризованные запросы / ORM?
   - ✅ Command Injection: проверка shell команд (`subprocess`, `os.system`)?
   - ✅ Template Injection: санитизация в Jinja2 шаблонах?
   - ✅ Path Traversal: проверка пользовательских путей файлов?

2. **Аутентификация и авторизация:**
   - ✅ Проверка прав доступа перед операциями
   - ✅ JWT токены валидируются правильно (алгоритм, истечение срока)?
   - ✅ Пароли хешируются с bcrypt / argon2 (не md5, не sha1)?
   - ✅ Timing attacks: сравниваются хеши через `secrets.compare_digest`?

3. **Работа с данными:**
   - ✅ Валидация всех входных данных (Pydantic)
   - ✅ Секреты не хардкодятся (используются env vars / pydantic-settings)?
   - ✅ Чувствительные данные не логируются (пароли, токены)?
   - ✅ HTTPS для передачи данных?

4. **Python-специфичные уязвимости:**
   - ✅ Нет `pickle.loads` с пользовательскими данными
   - ✅ Нет `eval` / `exec` с пользовательскими данными
   - ✅ Нет `yaml.load` (используй `yaml.safe_load`)
   - ✅ Нет прямого открытия файлов по пользовательскому пути без проверки

5. **Rate Limiting:**
   - ✅ Ограничение частоты запросов к API
   - ✅ Защита от brute force (auth endpoints)

6. **Зависимости:**
   - ✅ Актуальные версии библиотек
   - ✅ Нет известных уязвимостей (`pip-audit`)

**Результат:**
- 🔴 **CRITICAL:** Требует немедленного исправления
- 🟠 **HIGH:** Исправить в ближайшее время
- 🟡 **MEDIUM:** Желательно исправить
- 🟢 **LOW:** Улучшение безопасности

С конкретными примерами исправлений для каждой проблемы.
