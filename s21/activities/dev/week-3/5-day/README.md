# Финальный проект — Демонстрация (День 2)

**Формат:** 5 минут на команду/студента · Без слайдов · Живой запрос к системе

---

## Структура демо (5 минут)

1. **Задача (30 сек):** какую проблему решает агент, кто пользователь
2. **Архитектура (1 мин):** граф/схема компонентов, обоснование выбора паттерна
3. **Живое демо (2.5 мин):** три запроса — штатный, граничный, отказ
4. **Итог (1 мин):** что получилось, что не получилось, что бы изменили

---

## Критерии оценки

| Критерий | Зачёт |
| --- | --- |
| Агент работает в реальном времени | Да/Нет |
| Источники или трейс видны | Да/Нет |
| Граничный случай обработан | Да/Нет |
| Архитектурный выбор обоснован | Да/Нет |

---

## Ретроспектива (10 минут после всех демо)

Каждый студент отвечает на три вопроса (в чат или общий документ):

1. Что было самым сложным в реализации?
2. Какой компонент из курса вы бы использовали в реальном проекте прямо сейчас?
3. Что оказалось наиболее ценным из трёх недель?
