# День 8 (Неделя 2) • Практика: Cursor для бизнеса — глубокий вайб-кодинг

**Время:** 30–45 минут

Lovable из дня 3 — это сервис «один промпт = одна страница». Cursor — это полноценная среда, где ИИ работает с вашими файлами, помнит контекст, читает существующий проект, использует поиск и интернет. Сегодня вы соберёте более сложный артефакт — например, мини-сайт с несколькими страницами и единым стилем, или интерактивный калькулятор для отдела продаж, — и научитесь вести с ИИ диалог по доводке.

---

## Шаг 1: Установка и первый проект (10 минут)

**Что сделать:**

1. Установите Cursor: `cursor.com` — это редактор, очень похожий на VS Code, но с интегрированным ИИ
2. Войдите по бесплатному тарифу (Hobby) — достаточно для практики
3. Создайте папку проекта на рабочем столе, откройте её в Cursor: `File → Open Folder`
4. Нажмите `Ctrl/Cmd + L` — откроется панель чата с ИИ
5. Создайте файл `README.md`, опишите там задачу одним абзацем — это будет «техническое задание»

**Пример заполнения `README.md`:**

```
Мини-сайт «Калькулятор стоимости услуг»
Для кого: менеджеры по продажам
Что делает:
- Пользователь выбирает тип услуги (Базовый/Стандарт/Премиум)
- Указывает количество пользователей и срок (1/3/6/12 месяцев)
- Видит итоговую сумму со скидкой за срок
- Может скачать коммерческое предложение в PDF

Стиль: корпоративный, цвета компании — #0A4D8C и #F5A623
Хостинг: пока локально, потом — GitHub Pages
```

---

## Шаг 2: Промпт на генерацию полного проекта (15 минут)

Cursor может за один промпт создать несколько файлов сразу — это отличается от Lovable, где обычно один экран.

**Что сделать:**

1. В чате Cursor (`Ctrl/Cmd + L`) переключитесь в режим **Agent** или **Composer** (он умеет создавать файлы) — выпадающее меню над полем ввода
2. Прикрепите `README.md` к чату (значок `@` → `Files` → выбрать)
3. Отправьте промпт:

```
На основе README.md собери минималистичный мини-сайт.

Технические требования:
- Один HTML-файл + один CSS-файл + один JS-файл, без сборок
- Без backend, всё на клиенте
- Адаптивная вёрстка (мобильный + десктоп)
- Никаких внешних библиотек кроме того, что есть в браузере
- Цвета и стиль — из README

Что должно работать:
- Выбор услуги через radio-кнопки
- Ползунок или поле "Количество пользователей"
- Выпадающий список "Срок"
- Расчёт в реальном времени, без кнопки "Посчитать"
- Кнопка "Скачать PDF" — генерирует PDF через window.print()

Не добавляй комментарии в код — я не программист и они мне не нужны.
Создай файлы: index.html, styles.css, script.js
```

4. Cursor покажет, какие файлы создаст — нажмите «Apply All»
5. Откройте `index.html` двойным кликом — он откроется в браузере
6. Проверьте, что всё работает

**На что обратить внимание:** если что-то не работает — не паникуйте и не правьте код руками. Возвращайтесь в чат и опишите проблему так же, как описали бы коллеге: «когда я выбираю Премиум, сумма не меняется». Cursor увидит ваш код и поправит.

---

## Шаг 3: Доводка через диалог (15 минут)

Один промпт даёт каркас. Идеальный результат — через 3–5 итераций. Это нормально.

**Что сделать:**

1. Откройте свой прототип в браузере и проведите тест-драйв — попробуйте сломать
2. По каждому замечанию — отдельный промпт в Cursor (один маленький запрос за раз)
3. Примеры реальных итераций:

```
Запрос 1: "при выборе срока 12 месяцев должна автоматически
применяться скидка 15%, сейчас она не применяется"
```

```
Запрос 2: "сделай шапку с логотипом компании — пока заглушка
с текстом «КОМПАНИЯ» в той же палитре"
```

```
Запрос 3: "в PDF, который скачивается, должны быть только
выбранные параметры и итоговая сумма — сейчас попадают все
элементы интерфейса"
```

```
Запрос 4: "добавь поле e-mail клиента и кнопку «отправить КП на e-mail»
— пока без реальной отправки, открой mailto: с предзаполненной темой и телом"
```

4. После каждой итерации — снова проверьте в браузере
5. Финальная проверка — откройте сайт с телефона (через `127.0.0.1:5500` + локальный IP, или загрузите на GitHub Pages)

**На что обратить внимание:** если после правки сломалось что-то другое — нажмите `Ctrl/Cmd + Z` несколько раз, чтобы откатить файл, и переформулируйте запрос. Иногда лучше переписать промпт целиком, чем «спасать» испорченный результат.

---

## Шаг 4 (опционально): Публикация (5 минут)

Если проект работает и его хочется показать руководству или коллегам — выложите в интернет за пару минут.

**Что сделать (на выбор):**

- **GitHub Pages** — попросите Cursor: «помоги мне выложить этот проект на GitHub Pages, я никогда не работал с git, пошагово»
- **Vercel / Netlify** — перетащите папку в окно `app.netlify.com/drop` — сайт онлайн за 30 секунд
- **VK Mini App / Telegram Web App** — если нужно встроить во внутренний портал

Запишите ссылку в `README.md` рядом с описанием — это финальный артефакт.

---

## Итог дня

Через 30–45 минут у вас должно быть:
- Установленный Cursor с открытым проектом
- `README.md` с описанием реальной задачи
- 3 файла (`index.html`, `styles.css`, `script.js`), собранные за один промпт
- 3–4 итерации доводки через диалог
- (Опционально) Публичная ссылка на работающий прототип
