# День 9 (Неделя 2) • Практика: автоматизация бизнес-процесса в n8n

**Время:** 30–45 минут

В отдел приходят заявки с сайта на корпоративную почту. Дальше — ручная цепочка: ответственный читает письмо, копирует данные в Google-таблицу, кидает уведомление в Telegram-чат отдела. На каждую заявку — 5–7 минут, при 20 заявках в день это 2 часа рутины. Сегодня вы соберёте автоматический workflow в n8n — без программирования, через визуальный конструктор, — который замкнёт эту цепочку и срабатывает за секунды.

---

## Шаг 1: Запуск n8n (10 минут)

n8n — конструктор автоматизаций. Есть три способа запустить:

**Что сделать (выберите один путь):**

1. **n8n Cloud** (`n8n.io/cloud`) — самый простой, 14 дней бесплатно. Регистрация, и через 30 секунд готовая среда. Хорошо для теста, но для production придётся платить от $20/месяц
2. **Docker локально** — бесплатно, но данные только у вас на компьютере (то есть workflow не работает, пока компьютер выключен)
   ```bash
   docker run -p 5678:5678 -v ~/.n8n:/home/node/.n8n n8nio/n8n
   ```
   Открыть `http://localhost:5678`
3. **Собственный сервер** — Yandex Cloud / Selectel / VPS, $5–10/месяц. Подходит для постоянной работы, но требует базовых навыков администрирования

Для сегодняшней практики **n8n Cloud** — быстрее всего.

**На что обратить внимание:** в большинстве компаний на собственный сервер требуется согласование ИТ. Облако n8n может быть запрещено политикой безопасности — уточните у ИБ заранее, особенно если планируете прокачивать через workflow чувствительные данные.

## Шаг 2: Первый workflow — форма → таблица → уведомление (20 минут)

Соберите рабочую цепочку из трёх узлов под реальный сценарий.

**Что сделать:**

1. Создайте новый workflow, добавьте первый узел — **Trigger**:
   - Для теста — **Webhook** (POST-эндпоинт, на который можно слать запросы из формы)
   - Альтернатива — **Telegram Trigger** (новое сообщение боту), **Email Trigger** (новое письмо), **Google Forms** (через интеграцию)
2. Скопируйте URL вебхука и сохраните — он понадобится для теста
3. Добавьте второй узел — **Google Sheets** → `Append Row`:
   - Подключите свой Google-аккаунт (один клик)
   - Выберите таблицу для записи (или создайте новую с колонками: Дата, Имя, Email, Сообщение, Статус)
   - Подставьте данные из webhook: `{{ $json.body.name }}`, `{{ $json.body.email }}`, `{{ $json.body.message }}` — Cursor покажет автодополнение, когда вы кликнете в поле
4. Добавьте третий узел — **Telegram** → `Send Message`:
   - Подключите Telegram-бота (создайте через `@BotFather`)
   - В сообщении: ID чата отдела + текст:
     ```
     🆕 Новая заявка с сайта
     От: {{ $json.body.name }}
     Email: {{ $json.body.email }}
     Сообщение: {{ $json.body.message }}
     ```
5. Соедините узлы стрелочкой `Webhook → Sheets → Telegram`
6. Активируйте workflow (тумблер «Active» вверху справа)

**Промпт-помощник для встроенного AI Assistant (если вы запутались в узлах):**

```
Я хочу собрать workflow:
1. Принимает данные из веб-формы (POST-запрос с полями name, email, message)
2. Записывает строку в Google Sheets — лист "Заявки"
3. Отправляет уведомление в Telegram-чат с ID -1001234567890

Расскажи пошагово какие узлы добавить и какие поля заполнить.
```

## Шаг 3: Тест с реальным запросом (10 минут)

Workflow не сделан, пока вы не убедились, что он работает на реальном запросе.

**Что сделать:**

1. Скопируйте URL вебхука из первого узла
2. Отправьте тестовый POST-запрос. Самый простой способ — через curl или через **Postman / Hoppscotch** (`hoppscotch.io`):

```bash
curl -X POST [URL_вебхука] \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Иван Тестов",
    "email": "test@example.com",
    "message": "Тестовая заявка — проверяем workflow"
  }'
```

3. Проверьте: в Google Sheets появилась новая строка, в Telegram пришло уведомление
4. В n8n откройте раздел **Executions** — должна быть успешная запись с зелёной галочкой
5. Если где-то ошибка (красная иконка) — кликните на ошибочный узел и посмотрите детали; обычно проблема в неправильном маппинге полей

**Граничные случаи для проверки:**

- Что будет, если в `email` пустая строка? — добавьте узел **IF**, который отсекает невалидные заявки
- Что будет, если Google Sheets недоступен? — n8n повторит попытку 3 раза автоматически, но это можно настроить
- Что будет, если пришёл дубль (одна и та же заявка дважды)? — на следующий уровень: проверять по email через узел **Search Rows**, прежде чем добавлять

## Шаг 4 (опционально): Расширение workflow (5 минут)

После того как базовая цепочка работает, естественный следующий шаг — добавить «умную» обработку.

**Идеи на 5 минут:**

- **ChatGPT-узел** — попросите модель определить тип заявки («жалоба» / «запрос» / «спам») и в зависимости от типа уводить в разные чаты
- **Cron-триггер** — раз в неделю слать в чат сводку «количество заявок за неделю»
- **Условные ветки (Switch)** — заявки от VIP-клиентов уведомлять отдельно с пометкой
- **Запись в CRM** — Битрикс24 / amoCRM узлы есть в n8n из коробки

**На что обратить внимание:** не пытайтесь собрать «идеальный» workflow за один присест. Лучше: базовая цепочка → запустить → через неделю посмотреть, что хочется добавить → добавить.
