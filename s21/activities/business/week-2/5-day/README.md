# День 10 (Неделя 2) • Выходной — День России

**Время:** опционально, в своём темпе

12 июня — выходной по производственному календарю. Занятий нет. Если хочется потратить день с пользой и закрепить материал — ниже подборка свободных практик. Если хочется отдохнуть — это правильное решение, на следующей неделе будет финальный проект.

---

## Идеи опциональной практики

### 1. Доработать соло-проект недели 1

Если в прошлую пятницу проект остался «черновым» — самое время довести его до состояния, которым не стыдно поделиться с коллегами.

**Что можно улучшить:**
- Сделать инструкцию «как повторить за 10 минут» и передать одному коллеге
- Добавить ещё одну веху из stretch goals
- Заменить «захардкоженные» данные на реальные (с учётом правил безопасности из Дня 1)

---

### 2. Углубиться в один инструмент недели 2

Все четыре инструмента (картинки, боты, Cursor, n8n) — это отдельные глубокие темы. Выберите один, который ближе к работе, и потратьте день на «второй слой»:

| Инструмент | Что попробовать на втором уровне |
|---|---|
| Генерация изображений | Inpainting / Outpainting в Krea AI; согласованный персонаж через Character Reference в Midjourney; видео из картинки (Kling, Runway) |
| Боты | Подключение базы знаний к боту через RAG; голосовой бот через Aimylogic; A/B-тест двух версий сценария |
| Cursor | Сборка многостраничного сайта; интеграция с реальным backend (через ChatGPT API); деплой на Vercel |
| n8n | Connecting к Битрикс24 / amoCRM; AI-узел с классификацией заявок; обработка ошибок и retry |

---

### 3. Собрать дайджест инструментов для коллег

Превратите свои заметки за две недели в один документ, которым можно поделиться с командой.

**Структура дайджеста (1–2 страницы):**

```
# Что я изучил за две недели

## Инструменты, которые внедряю прямо сейчас
- [Инструмент 1] — для [задача], экономит [время]
- ...

## Инструменты, которые попробую в течение месяца
- ...

## Инструменты, которые НЕ подходят моей задаче и почему
- ...

## Безопасность: что я НЕ отправляю в ИИ
- ...

## Полезные ссылки и шаблоны промптов
- ...
```

Сохраните в общую папку отдела или прикрепите к календарному событию для команды.

---

### 4. Подготовить идею финального проекта

В среду (день 13) — обсуждение финального проекта. Кто пришёл с готовой идеей — тот выходит из обсуждения с проработанным планом, а не с тремя вариантами «может быть».

**Что сделать заранее:**

```
Моя бизнес-задача: ____________________________________
Кто пользователь решения: ____________________________
Сколько времени я трачу сейчас: ______________________
Сколько хочу сэкономить: ______________________________
Какие инструменты из курса применю: __________________
Что покажу на демо (что увидят на экране за 5 минут): _
```
