# День 6 (Неделя 2) • Практика: генерация креатива — изображения и раскадровка

**Время:** 30–45 минут

Маркетинг готовит кампанию по новому продукту. Нужны: визуал для соцсетей, обложка для презентации, набросок раскадровки 30-секундного ролика. Бюджет на агентство не выделили, дизайнер занят до конца месяца. Раньше — невозможно, сегодня — реально за полчаса собрать каркас, который дизайнер потом доведёт до брендбука.

---

## Шаг 1: Промпт для изображения — структура (5 минут)

Случайный промпт даёт случайную картинку. Хороший промпт = сюжет + стиль + ракурс + свет + что не должно быть.

**Шаблон промпта на русском:**

```
Сюжет: [что/кто на изображении, действие]
Стиль: [фотореализм / иллюстрация / 3D-рендер / акварель / ...]
Композиция: [крупный план / средний / общий, центрированно / по правилу третей]
Освещение: [студийный / закатный / контровой / приглушённый]
Цветовая палитра: [тёплая / холодная / монохром / конкретные цвета]
Настроение: [спокойное / энергичное / деловое / ...]
Что НЕ должно быть: [люди / текст / логотипы / лишние объекты]
Соотношение сторон: [16:9 / 1:1 / 4:5]
```

**Пример (обложка для презентации):**

```
Сюжет: рабочий стол с открытым ноутбуком, рядом — записная книжка и чашка кофе
Стиль: чистый фотореализм, корпоративная фотография
Композиция: вид сверху, диагональное расположение
Освещение: мягкий дневной свет от окна слева
Палитра: тёплый бежевый, тёмно-синий акцент
Настроение: деловое, спокойное
Не должно быть: людей, видимого экрана с интерфейсом, посторонних предметов
Соотношение сторон: 16:9
```

**На что обратить внимание:** на английском современные модели работают лучше — переведите промпт в ChatGPT/Нейрофонд одной кнопкой. И не пытайтесь получить картинку с текстом — модели до сих пор плохо отрисовывают шрифты, кириллицу особенно.

## Шаг 2: Параллельная генерация в двух сервисах (15 минут)

Разные модели — разные сильные стороны: одна сильнее в фотореализме, другая в иллюстрации, третья знает русские реалии.

**Что сделать:**

1. Возьмите свой промпт из Шага 1 и сгенерируйте картинку **в двух разных сервисах**:
   - **Российские:** «Шедеврум» (Yandex), Kandinsky, GigaChat-Vision
   - **Зарубежные:** Midjourney (через Discord или midjourney.com), DALL-E 3 в ChatGPT, Flux в FAL
2. Заполните мини-таблицу:

| Критерий | Сервис A | Сервис B |
|---|---|---|
| Понял ли стиль? | | |
| Качество деталей | | |
| Сходство с задумкой | | |
| Артефакты («лишние пальцы», искажения) | | |
| Можно использовать без правок? | | |
| Цена за 4 варианта | | |

3. Выберите 1–2 лучших варианта, сохраните в папку проекта

**На что обратить внимание:** правило 4-х генераций — никогда не берите первую попавшуюся. Запросите минимум 4 варианта одного и того же промпта (большинство сервисов делает это по умолчанию) и выберите лучший. Иногда тот, что «номер 4» оказывается заметно лучше «номера 1».

## Шаг 3: Раскадровка под бизнес-кейс (15 минут)

Для ролика, презентации или статьи в соцсетях обычно нужна не одна картинка, а серия — связанная сюжетом. Это называется storyboard (раскадровка).

**Что сделать:**

1. Сформулируйте сюжет за 4–6 кадров для своего реального кейса. Например:
   - 30-секундный ролик «как работает наш сервис»: проблема → герой пробует → решение → счастливый итог
   - Серия из 5 картинок для статьи: вступление, проблема, метод, результат, призыв
   - Презентация на 6 слайдов: один слайд = одно изображение-метафора
2. Опишите каждый кадр в одну строку и сгенерируйте серию. Для согласованного стиля используйте один и тот же базовый промпт + меняющуюся сюжетную часть:

```
Базовый стиль: чистая иллюстрация в плоском дизайне, цветовая палитра — синий, белый, оранжевый акцент, без текста, без лиц крупным планом.

Кадр 1: офисный работник за заваленным бумагами столом
Кадр 2: тот же работник смотрит на экран ноутбука с виджетом «сводка готова»
Кадр 3: работник радостно отправляет письмо
Кадр 4: тот же работник в кофейне, расслабленный — на часах 17:00
```

3. Соберите получившиеся 4–6 изображений в один файл (Google Slides / PowerPoint / Figma) — это и есть раскадровка
4. Запишите 1–2 наблюдения: что получилось согласованно, где модель «забыла» стиль

**На что обратить внимание:** согласованность персонажа между кадрами — слабое место всех моделей. Если важно «один и тот же герой» — используйте режим **Character Reference** в Midjourney (`--cref [ссылка]`) или функции «edit» в Flux/Kandinsky. Альтернатива — описать героя максимально обобщённо: «офисный работник, мужчина 35 лет, синяя рубашка», без точных черт.

## Шаг 4 (опционально): Согласование с брендбуком (5 минут)

Даже идеальная картинка может не пройти согласование, если она вне бренда.

**Что сделать:**

1. Откройте брендбук компании или его упрощённую версию (логотип, цвета, шрифты)
2. Прогоните ваши результаты через чек-лист:

```
- [ ] Цвета попадают в палитру бренда
- [ ] Нет конкурентов / чужих логотипов в кадре
- [ ] Стиль соответствует tone of voice (не лёгкомысленный для серьёзного продукта)
- [ ] Можно использовать в РФ без вопросов (символика, флаги, спорные сюжеты)
- [ ] Лицензия сервиса разрешает коммерческое использование
```

3. Если что-то не сходится — сгенерируйте новую версию с правкой в промпте: «палитра только синий и серый, без оранжевого»

## Итог дня

Через 30–45 минут у вас должно быть:
- Шаблон промпта для изображения, заполненный под свою задачу
- Минимум 2 варианта одного изображения в разных сервисах с таблицей сравнения
- Раскадровка из 4–6 кадров под реальный бизнес-кейс
- (Опционально) Чек-лист соответствия брендбуку
