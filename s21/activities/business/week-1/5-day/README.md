# Соло-проект • Неделя 1 — Применить инструменты недели в своей работе

**Формат:** самостоятельная работа, без преподавателя  
**Время:** ~2 часа на реализацию + 1 час на показ результатов  
**Результат:** одна реальная рабочая задача, автоматизированная или ускоренная с помощью инструментов недели 1

---

## Контекст

За эту неделю вы научились: писать рабочие промпты, сравнивать модели, готовить материалы с проверкой источников, собирать прототипы интерфейсов и автоматизировать Google-таблицы. Сегодня — собрать всё в один маленький продукт, который реально сэкономит ваше время в ближайший месяц.

Главное правило: **выбирайте задачу из своей реальной работы, а не учебную.**

---

## Шаг 1: Выбор задачи (15 минут)

Выберите одну задачу, которая отвечает условиям:

- Вы делаете её **минимум раз в неделю**
- На неё уходит **≥ 30 минут** ручной работы
- Результат — **что-то осязаемое**: документ, письмо, таблица, прототип
- В ней **нет персональных данных третьих лиц** (или их легко обезличить)

**Примеры подходящих задач:**

| Задача | Какие инструменты применить |
|---|---|
| Еженедельная сводка по продажам в чат отдела | Apps Script + Sheets + триггер по расписанию |
| Подготовка к ежемесячному совещанию: собрать материалы и выводы | Wisper + Perplexity + NotebookLM |
| Мини-каталог инструкций по продукту для новичков | Lovable / Claude Artifacts |
| Шаблон ответа клиенту в типовой ситуации | Шпаргалка промптов + ChatGPT |
| Дайджест отраслевых новостей раз в неделю | Perplexity + ChatGPT для саммари |
| Обработка ответов из Google-формы (опрос сотрудников) | Apps Script + Gmail |

Заполните для себя:

```
Моя задача: ____________________________________________
Как часто делаю: ______________________________________
Сколько времени уходит сейчас: ________________________
Какие инструменты применю: ___________________________
Какой будет финальный артефакт: ______________________
```

---

## Шаг 2: Реализация (~1.5 часа)

Работайте по вехам — это позволит вовремя понять, что что-то идёт не туда, и переключиться на запасной план.

### Веха 1: Постановка задачи и первый промпт (20 минут)

**Готово когда:**
- В Google Docs / заметках записан подробный шаблон задачи (что → для кого → как часто → итог)
- Сформулирован первый рабочий промпт для ИИ
- Промпт протестирован на ИИ — результат «понятен и почти подходит»

---

### Веха 2: Черновой результат (40 минут)

**Готово когда:**
- Получен первый рабочий вариант — пусть некрасивый, но работающий
- Если это автоматизация — скрипт/прототип запущен на тестовых данных
- Если это документ — есть черновик с фактической информацией, а не «болванка»

---

### Веха 3: Доводка и фиксация (30 минут)

**Готово когда:**
- Решение работает на реальных данных (с заменой персональных данных при необходимости)
- Записан текст промпта или сохранён код — чтобы можно было запустить ещё раз
- Записано: где результат «слабоват» и что нужно доработать в будущем

---

## Требования к результату

**Обязательно:**
- [ ] Используется минимум **один** инструмент из недели 1
- [ ] Результат можно показать за 2 минуты — есть что открыть на экране
- [ ] В отчёте: оценка «было / стало» по времени
- [ ] Соблюдены правила безопасности из Дня 1 — нет утечки персональных данных

**Желательно:**
- [ ] Использовано **два и более** инструмента из недели — например, ChatGPT для текста + Apps Script для рассылки
- [ ] Описаны ограничения: где сейчас работает плохо, что нужно ИТ-отделу для масштабирования

---

## Формат демо (5 минут на участника)

В понедельник в начале занятия — мини-демо:

1. **Что за задача (1 мин)** — какую боль решает, как часто возникает
2. **Что сделано (2 мин)** — живая демонстрация: открыть прототип / запустить скрипт / показать промпт и ответ
3. **Что получилось (1 мин)** — было/стало по времени, что удивило
4. **Что не получилось (1 мин)** — где упёрлись, что отложили на потом

Без слайдов. Лучше — экран с реальным инструментом.

---

## Stretch goals

Если основной сценарий готов раньше времени:

**+Передача коллеге.** Опишите задачу в виде инструкции «как повторить за 10 минут» и попросите коллегу пройти по шагам. Если коллега упёрся — допишите шаг, который выпал.

**+Метрики.** Запишите перед запуском: сколько минут уходило раньше. После недели использования — сколько уходит сейчас. Простая разница = экономия времени за месяц.

**+Безопасный шаблон.** Если в задаче были чувствительные данные — сделайте шаблон для коллег с правилами «что подставлять / что не подставлять».

## Подсказки

**Задача оказалась слишком большой.**  
Разбейте: сегодня делаем самую болезненную часть — не весь процесс.

**Промпт даёт «воду».**  
Возьмите шпаргалку из Дня 1 и пересоберите промпт по структуре «Роль + Задача + Контекст + Формат + Ограничения». Часто помогает добавить негативный пример: «Так — не надо: …».

**Apps Script ругается на разрешения.**  
В первый запуск Google спрашивает доступ к Sheets/Gmail — это нормально. Если показывает «приложение не проверено» — нажмите «Дополнительно → перейти в редактор».

**Lovable собрал не то, что хотел.**  
Не пишите «исправь всё», лучше один маленький запрос за раз: «увеличь шапку», «убери поле email», «добавь поиск». Так ИИ не запутается.

**Хочется большее — кончается время.**  
Сегодня цель — сделать одну вещь, которая работает. Расширение оставляйте на следующую неделю.
