# День 4 (Неделя 1) • Практика: Google Workspace + ИИ — Apps Script как «клей»

**Время:** 30–45 минут

Каждую пятницу вы вручную собираете отчёт: открываете три Google Sheets, копируете строки за неделю в сводную таблицу, делаете рассылку коллегам в Gmail. Это занимает час. Сегодня вы автоматизируете один такой сценарий — без знания кода, через диалог с ИИ. Apps Script — это бесплатный сервер Google, который умеет работать с Sheets, Gmail, Drive и Calendar без установки чего-либо на ваш компьютер.

---

## Шаг 1: Формула или скрипт — где граница? (5 минут)

Прежде чем тянуться к Apps Script, проверьте — может, обычной формулы достаточно. Формулы работают мгновенно и не требуют разрешений; скрипт нужен там, где формул мало.

**Что сделать:**

1. Прочитайте таблицу и отметьте, что относится к вашей реальной задаче:

| Задача | Достаточно формулы | Нужен скрипт |
|---|---|---|
| Посчитать сумму / среднее за период | ✅ `SUMIFS` | |
| Получить курс валюты на сегодня | ✅ `GOOGLEFINANCE` | |
| Найти строки, где «срок < сегодня» | ✅ `FILTER` + `TODAY()` | |
| По кнопке отправить таблицу на e-mail | | ✅ |
| Каждый понедельник в 9:00 отправить сводку | | ✅ |
| Создать 50 документов из шаблона по строкам таблицы | | ✅ |
| По событию в форме отправить ответ + уведомить меня в Telegram | | ✅ |
| Подтянуть данные из 5 других таблиц | ✅ `IMPORTRANGE` (если простые) | ✅ (если сложно) |

2. Выберите для дальнейшей практики одну задачу из правой колонки — это сценарий, который вы автоматизируете

**На что обратить внимание:** «маленький скрипт + формулы» обычно лучше, чем «один большой скрипт». Скрипты можно сломать неловким редактированием, формулы — нет.

## Шаг 2: Первый Apps Script через ИИ (15 минут)

**Что сделать:**

1. Откройте свою Google-таблицу с реальными данными (или скопируйте [демо-таблицу](https://docs.google.com/spreadsheets/d/1example) — заведите 10 строк с тестовыми данными)
2. Меню: `Расширения → Apps Script` — откроется редактор
3. Сформулируйте задачу для ИИ по шаблону:

```
Напиши Google Apps Script для моей задачи.

Что должен делать скрипт:
[описание простым языком, шаг за шагом]

Структура таблицы:
Лист "[имя]", колонки:
A: [название] — [тип данных]
B: [название] — [тип данных]
...

Где запускать:
- кнопкой в таблице
- автоматически по расписанию (раз в день в 9:00)
- по событию (новая строка / отправлена форма)

Что должно произойти:
[итоговый результат — отправленное письмо, заполненная колонка и т.д.]

Объясни на русском что делает каждый блок кода — я не программист.
```

4. Скопируйте полученный код в редактор, нажмите ▶️ Run
5. При первом запуске дайте разрешения (Google спросит — это нормально)
6. Проверьте результат

**Пример промпта для реальной задачи:**

```
Напиши Google Apps Script для еженедельной рассылки сводки.

Что должен делать:
1. Каждую пятницу в 17:00
2. Открыть лист "Продажи" в текущей таблице
3. Отфильтровать строки, где дата в колонке D попадает в текущую неделю
4. Посчитать сумму по колонке E (выручка) и количество строк
5. Отправить письмо на адреса из ячейки A1 другого листа "Настройки"
6. В письме: тема "Сводка за [даты недели]", тело — сумма и количество

Структура листа "Продажи":
A: дата (date)
B: менеджер (text)
C: клиент (text)
D: сумма сделки (number)

Объясни код на русском по блокам.
```

**На что обратить внимание:** в первый раз код запустится без триггера — то есть один раз вручную. Триггер «по расписанию» настраивается отдельно в редакторе скриптов (значок будильника слева).

## Шаг 3: Триггер и проверка (15 минут)

Скрипт, который надо запускать руками — это не автоматизация. Триггер заставляет его работать сам.

**Что сделать:**

1. В редакторе Apps Script слева выберите ⏰ **Триггеры**
2. Нажмите «Добавить триггер» и настройте:
   - Функция: ваша главная функция из скрипта
   - Источник события: «Управляется по времени» или «Из таблицы»
   - Для «По времени»: «Триггер по неделям» → пятница → 16:00–17:00
   - Для «Из таблицы»: «При отправке формы» или «При изменении»
3. Сохраните и подождите следующего срабатывания (или вручную поменяйте дату для проверки)
4. Проверьте логи: `Выполнения` слева — там видно, сработал ли триггер и были ли ошибки
5. Если ошибка — скопируйте текст ошибки в ChatGPT/Нейрофонд и попросите исправить, приложив текущий код

**На что обратить внимание:** у Apps Script есть лимиты — например, 100 отправленных писем в день для бесплатного аккаунта, 1 500 для платного Workspace. Если планируете массовую рассылку — проверьте лимит заранее.

## Шаг 4 (опционально): Подсказки по отладке (5 минут)

Если скрипт ведёт себя странно — стандартные приёмы:

- **Добавьте `console.log()`** в ключевых местах — потом в `Выполнения` видны значения переменных. Промпт ИИ: «добавь подробное логирование, чтобы я мог понять что не так»
- **Проверьте часовой пояс** таблицы и скрипта: `Настройки проекта → Часовой пояс` — должен быть Europe/Moscow для пятничного триггера на 17:00
- **Если письмо не приходит** — проверьте папку Спам и квоту: `Сервис → MailApp.getRemainingDailyQuota()`
- **Сохраняйте копию рабочего кода** в комментарии или в Google Docs перед каждой большой правкой — Apps Script хранит историю, но не всегда удобно откатываться
