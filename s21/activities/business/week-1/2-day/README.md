# День 2 (Неделя 1) • Практика: Wisper, Perplexity, NotebookLM

**Время:** 30–45 минут

Через неделю — презентация по новому рынку для совета директоров. Нужно: 1) перевести часовую запись интервью с экспертом в текст и достать оттуда выводы, 2) собрать материалы по теме из открытых источников и проверить, что цифры реальные, а не выдуманные ИИ, 3) сделать обучающий мини-подкаст для команды, чтобы они тоже были в теме. Раньше это заняло бы 2 дня — сегодня вы сделаете каркас за час.

---

## Шаг 1: Транскрибация записи и саммари (10 минут)

Запись разговора в текст — базовая операция, на которой строятся все остальные. Сегодня делаем это за минуты.

**Что сделать:**

1. Возьмите любую запись на 5–10 минут — реальное совещание (без чувствительных данных), запись доклада с YouTube или собственный голосовой меморандум
2. Транскрибируйте одним из инструментов:
   - **MacWhisper / WhisperX** — локально, бесплатно, без отправки в облако
   - **Wispr Flow / Yandex Cloud SpeechKit** — облако, удобный UI
   - **NotebookLM** (`notebooklm.google.com`) — сразу загружает аудио и делает саммари
3. Скопируйте получившийся текст в ChatGPT/Нейрофонд с промптом:

```
Ниже стенограмма [совещания/интервью]. Сделай краткое саммари в формате:
1. Главное (3 пункта)
2. Принятые решения (если были)
3. Открытые вопросы (что не решили)
4. Действия с дедлайнами (кто-что-когда)
Если в стенограмме что-то непонятно или противоречит — отметь это явно.

Стенограмма:
[вставить текст]
```

4. Сравните: что в исходной записи и что в саммари — нет ли потерь смысла

**На что обратить внимание:** Whisper иногда путает имена и термины — особенно русские. Перед саммари можно попросить ChatGPT: «исправь возможные ошибки распознавания имён и терминов, контекст: совещание отдела закупок». Это улучшает результат сильнее, чем кажется.

---

## Шаг 2: Perplexity против ChatGPT — поиск с источниками (15 минут)

ChatGPT может выдумать ссылку, дату или цифру — это называется галлюцинация. Perplexity по умолчанию отвечает с указанием источников, и каждое утверждение можно перепроверить.

**Что сделать:**

1. Сформулируйте одну реальную исследовательскую задачу из работы:
   - «Какие основные игроки на рынке X в России в 2024–2025?»
   - «Какие изменения в законе об маркировке товаров вступили в силу в этом году?»
   - «Какие выводы делают аналитики о трендах в [нашей отрасли]?»
2. Задайте этот вопрос в **трёх** местах:
   - **Perplexity** (`perplexity.ai`) — с включённым режимом «Pro» если есть
   - **ChatGPT с веб-поиском** (`chatgpt.com`, кнопка глобуса)
   - **Yandex GPT / GigaChat с поиском** — если используете
3. Заполните таблицу:

| Критерий | Perplexity | ChatGPT | Yandex/Giga |
|---|---|---|---|
| Кол-во источников | | | |
| Из них реальных (открыли ссылку — работает?) | | | |
| Дата самой свежей информации | | | |
| Есть ли противоречия между источниками? | | | |
| Можно ли использовать в отчёте без проверки? | | | |

4. Найдите минимум один факт, где модели расходятся — это и есть точка, требующая ручной проверки

**На что обратить внимание:** даже Perplexity иногда ссылается на источник, в котором утверждения нет — он опирается на формулировку, выбранную алгоритмом. Правило: **любую цифру в отчёте проверяйте по первоисточнику.**

## Шаг 3: NotebookLM — подкаст или инфографика для команды (15 минут)

NotebookLM умеет принять на вход несколько документов и сгенерировать на их основе обучающий мини-подкаст (двое ведущих обсуждают тему) или mind map / FAQ для самостоятельного изучения.

**Что сделать:**

1. Откройте `notebooklm.google.com`, создайте новый блокнот
2. Загрузите 2–3 источника по теме своей задачи:
   - PDF-отчёт, статью с РБК / Коммерсанта, презентацию по продукту
   - Стенограмму из Шага 1
   - Ответы Perplexity (можно скопировать в Google Docs и подгрузить)
3. Выберите формат вывода:
   - **Audio Overview** — 5–10-минутный «подкаст» на двоих, можно загрузить в Telegram для команды
   - **Briefing Doc** — краткая выжимка с фактами
   - **Mind Map** — визуальная схема, удобная для подготовки к презентации
4. Послушайте подкаст / просмотрите бриф — отметьте 2–3 места, где он либо ошибся, либо упустил важное

**На что обратить внимание:** NotebookLM редко галлюцинирует, потому что ограничен загруженными материалами. Но он умеет переставлять акценты — если в отчёте критика в конце, в подкасте она может оказаться вскользь. Перед публикацией для команды слушайте сами.
