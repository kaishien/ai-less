# День 1 (Неделя 1) • Практика: первое знакомство с LLM на работе

**Время:** 30–45 минут

Вы — менеджер среднего звена. После летних отпусков накопилось: 47 непрочитанных писем, 6 запросов из соседних отделов, черновик отчёта руководству. На прошлом совещании директор сказал: «учитесь пользоваться ИИ — иначе через год будем искать тех, кто умеет». Сегодня — первая практическая сессия. К концу часа вы должны иметь свою рабочую «шпаргалку» промптов, понимать, какие данные нельзя отправлять в облако, и (по желанию) запустить локальную модель.

---

## Шаг 1: Шпаргалка из 5 промптов под свои задачи (15 минут)

Большинство людей пишут в ChatGPT «помоги составить письмо» и удивляются посредственному результату. Хороший промпт = роль + задача + контекст + формат + ограничения.

**Что сделать:**

1. Откройте «Нейрофонд» (или ChatGPT, GigaChat — что у вас доступно)
2. Вспомните 5 типовых задач из своей недели — например:
   - письмо отказа подрядчику
   - сводка по 3-страничной заявке для руководителя
   - таблица сравнения двух предложений
   - повестка совещания по результатам месяца
   - ответ на «токсичное» письмо без эскалации
3. Для каждой задачи запишите промпт по шаблону ниже
4. Сохраните 5 промптов в заметках или в отдельной таблице — это ваша шпаргалка

**Шаблон промпта:**

```
Роль: ты — [кто] с опытом [контекст]
Задача: [что нужно получить]
Контекст: [короткие факты — без ФИО, цифр контрактов и т.д.]
Формат: [письмо в 4 абзаца / таблица 3×N / список с буллетами]
Ограничения: [тон, длина, что нельзя]
```

**Пример (письмо отказа):**

```
Роль: ты — менеджер по закупкам с 5-летним опытом, тон вежливый, но твёрдый
Задача: написать письмо отказа подрядчику по итогам тендера
Контекст: подрядчик не прошёл по цене, но в тендере участвовал второй раз
Формат: письмо на 4 абзаца, без шаблонных формулировок «к сожалению»
Ограничения: без обещаний пересмотреть решение, без обвинений
```

**На что обратить внимание:** один и тот же запрос без роли/формата/ограничений даёт «размытый» ответ. Сравните два варианта на одной задаче.

---

## Шаг 2: Сравнить две модели на одной задаче (10 минут)

Не все модели одинаково сильны: одна хорошо пишет, другая лучше анализирует, третья дешевле. На простой задаче разницы почти нет — на сложной видна сразу.

**Что сделать:**

1. Возьмите один сложный промпт из своей шпаргалки (например, сводку по большой таблице)
2. Отправьте ровно один и тот же текст в две модели:
   - ChatGPT (GPT-4o / GPT-5)
   - GigaChat / YandexGPT / Claude — на выбор
3. Запишите в таблицу:

| Критерий | Модель A | Модель B |
|---|---|---|
| Понял задачу с первого раза? | | |
| Структура ответа | | |
| Конкретность (или «вода»?) | | |
| Что бы исправил вручную? | | |

4. Сделайте вывод: какая модель подходит для каких ваших задач

**На что обратить внимание:** даже если модель A «умнее» в среднем, для коротких типовых задач часто проще и быстрее модель B. Замерьте не только качество, но и скорость ответа.

## Шаг 3: Чеклист безопасности — что НЕ отправлять в ИИ (10 минут)

Внутри облачного ИИ ваши промпты могут быть использованы для обучения модели, попасть в логи провайдера, а через интегрированные плагины — уйти ещё дальше. Для одних данных это допустимо, для других — нарушение политики компании или закона (152-ФЗ).

**Что сделать:**

1. Откройте таблицу ниже и заполните для своей роли
2. Для каждого пункта поставьте: ✅ можно / ⚠️ только обезличенно / ❌ запрещено

| Тип данных | Облачный ChatGPT | Корпоративный «Нейрофонд» | Локальная LLM |
|---|---|---|---|
| Текст письма без ФИО и цифр | | | |
| Письмо с ФИО клиентов | | | |
| Договор с реквизитами | | | |
| Финансовый отчёт за квартал | | | |
| Список зарплат сотрудников | | | |
| Скан паспорта | | | |
| Стенограмма внутреннего совещания | | | |

3. Запишите в шпаргалку правило для себя: «Перед отправкой в ИИ я убираю: …»

**На что обратить внимание:** чаще всего нарушение происходит не злонамеренно, а по инерции — скопировал документ целиком, не заметил, что внутри ФИО. Полезный приём: перед отправкой пройдитесь по тексту и замените реальные данные на «Иванов И. И.», «ООО Ромашка», «100 000 руб.».

## Шаг 4 (опционально): Локальная LLM на своём компьютере (10 минут)

Если данные нельзя отправлять в облако — единственный вариант это локальная модель, которая работает у вас на ноутбуке и никуда ничего не отправляет.

**Что сделать:**

1. Установите один из инструментов:
   - **LM Studio** (`lmstudio.ai`) — самый простой, есть UI, работает на Windows / macOS / Linux
   - **Ollama** (`ollama.com`) — через терминал, легче на ресурсы
2. Скачайте модель под свою машину:
   - 8 ГБ RAM — `qwen2.5:7b` или `llama3.1:8b`
   - 16 ГБ RAM — `gemma2:9b` или `qwen2.5:14b`
3. Задайте тот же промпт, что в Шаге 1, и сравните с облачным ответом
4. Запишите: что хуже, что приемлемо, для каких задач локальной модели достаточно

**На что обратить внимание:** локальная модель в 5–10 раз медленнее облачной и заметно слабее в сложных задачах. Но для саммари письма или черновика короткого ответа она вполне справляется — а данные не выходят за периметр.
