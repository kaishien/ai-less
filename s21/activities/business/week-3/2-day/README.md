# День 12 (Неделя 3) • Практика: ИИ-агенты — Open Claw и принципы безопасного использования

**Время:** 30–45 минут

Все предыдущие дни вы работали с ИИ в режиме «чат-ответ»: задаёте вопрос — получаете ответ. ИИ-агент — следующий уровень: он сам открывает браузер, ищет, кликает, заполняет формы, читает PDF, отправляет письма. Сегодня вы посмотрите, как это работает на одном из публичных агентов (Open Claw / Comet / Manus), попробуете дать ему реальную задачу — и заодно составите чеклист, что агенту можно поручать в вашей компании, а что — нет.

---

## Шаг 1: Что такое агент в отличие от чата (5 минут)

Прежде чем запускать — поймём, чем агент отличается от ChatGPT.

| | Чат (ChatGPT, GigaChat) | Агент (Open Claw, Comet, Manus) |
|---|---|---|
| Что делает | Отвечает текстом | Выполняет шаги в реальных интерфейсах |
| Длина задачи | 1 вопрос | 10–50 шагов |
| Среда | Окно чата | Открывает браузер, файлы, API |
| Кто контролирует | Вы — каждый ответ | Вы — задаёте цель, проверяете итог |
| Ошибки | Текстовая галлюцинация | Может сделать действие, которое потом сложно откатить |
| Подходит для | разовых вопросов, текстов | повторяющихся многошаговых задач |

**Примеры задач для агента:**
- «Зайди на сайты 5 конкурентов и сделай таблицу с их ценами»
- «Открой почту, найди письма от клиента X за месяц, собери резюме переписки»
- «Скачай 10 PDF-отчётов с сайта Росстата по моему региону и сведи цифры в таблицу»

**Примеры задач НЕ для агента:**
- Любая задача, где ошибка стоит дорого — оплата, документы, отправка финального решения клиенту
- Задачи на работе с персональными данными третьих лиц
- Любые действия от вашего имени в системах, где есть log of activity и ответственность

## Шаг 2: Демо публичного агента (15 минут)

**Что сделать:**

1. Выберите один из доступных публичных агентов:
   - **Open Claw / Comet** — браузерные агенты, есть бесплатные демо-режимы
   - **Manus** (`manus.im`) — китайский агент, бесплатные кредиты на старте
   - **ChatGPT Agent Mode** — если у вас Plus/Pro подписка, режим «Agent» в Operator
   - **Perplexity Comet** — поисковый агент-браузер (`comet.perplexity.ai`)
   - **Browser Use** + локальная LLM — open source вариант для тех, кто не хочет давать доступ к интернету сторонним сервисам
2. Сформулируйте безопасную тестовую задачу (без работы в реальных корпоративных системах):

```
Задача:
Зайди на сайт habr.com, найди 5 самых популярных статей
за последнюю неделю в разделе "Искусственный интеллект".
Собери таблицу: название, автор, дата, краткое содержание в одно предложение,
ссылка. Выведи в формате Markdown.
```

3. Запустите задачу и наблюдайте — у большинства агентов есть режим «следить за тем, что делает агент в реальном времени»
4. Заполните наблюдения:

```
Что агент сделал хорошо: _________________________________
Где запутался / повторил действие: ______________________
Время выполнения: _______________________________________
Сколько раз вмешался руками: ____________________________
Доверил бы ему задачу без проверки? _____________________
```

**На что обратить внимание:** агент — это всегда «черновик». Финальный результат должен проверять человек. И никогда не давайте агенту доступ к боевым корпоративным системам — для теста подойдут публичные сайты или копии данных в тестовом окружении.

## Шаг 3: Чеклист допустимого использования ИИ для своей роли (15 минут)

Кейсов с агентами на работе становится всё больше. Если у вашей компании ещё нет внутреннего регламента — вы сами должны понимать, где граница.

**Что сделать:**

Составьте свой чеклист в формате «можно / нельзя / только с согласованием» для своей конкретной роли. Заполните таблицу:

| Сценарий | Можно? | Условия |
|---|---|---|
| Отправлять в ChatGPT публичные документы (PDF с сайта, открытые отчёты) | | |
| Отправлять внутренние документы без персональных данных | | |
| Отправлять документы с ФИО клиентов | | |
| Отправлять документы с финансовыми показателями компании | | |
| Использовать ИИ для написания черновика письма клиенту от моего имени | | |
| Использовать ИИ для написания финального коммерческого предложения | | |
| Использовать агента для сбора публичных данных (сайты конкурентов) | | |
| Использовать агента для работы в моих рабочих системах (CRM, почта, банк) | | |
| Загружать запись внутреннего совещания в облачный сервис транскрибации | | |
| То же, но через локальный Whisper | | |
| Генерировать иллюстрации для внешней публикации от лица компании | | |
| Использовать ИИ для кода/скриптов, обрабатывающих коммерческие данные | | |

Для каждой «нельзя» строки запишите **зачем** это правило: «потому что…».

**Шаблон финального документа:**

```
# Регламент использования ИИ — [моя роль]

## Можно без ограничений
1. ...
2. ...

## Можно с обезличиванием
1. ... — заменяю ФИО на "Иванов И.И.", цифры — на округлённые
2. ...

## Только в локальных моделях / корпоративном "Нейрофонде"
1. ...

## Запрещено в любом виде
1. ...

## Что я делаю с результатом ИИ
- Всегда проверяю факты по первоисточнику
- Всегда читаю до конца перед отправкой
- Никогда не использую как финальный документ без правки
```

**На что обратить внимание:** этот чеклист — для вас лично, а не для коллег. У каждой роли разные ограничения. Юрист и маркетолог по разному оценивают допустимое использование одних и тех же данных. После недели работы с чеклистом — обновите его на основе реальных кейсов.

## Шаг 4 (опционально): Где взять корпоративный регламент (5 минут)

Если в компании нет регламента — есть готовые шаблоны, на основе которых можно собрать свой.

**Что посмотреть:**

- [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework) — мировой стандарт
- Кодекс этики в сфере ИИ (Россия) — opinion-документ Альянса в сфере ИИ
- Образцы политик от OpenAI, Anthropic — для компаний-клиентов: что компания сама от себя ожидает
- Внутренний чат с ИБ и юристами — самый важный источник для вашей конкретной компании
