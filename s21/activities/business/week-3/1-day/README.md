# День 11 (Неделя 3) • Практика: презентации в Gamma, Kimi и GigaChat

**Время:** 30–45 минут

В пятницу — выступление на 5 минут перед руководством по итогам пилота. Слайды нужны вчера, дизайнер занят, шаблон в PowerPoint скучный. Сегодня вы соберёте две версии одной и той же презентации в двух разных инструментах, сравните результаты и выберите оптимальный путь для будущих выступлений.

---

## Шаг 1: Структура выступления (10 минут)

Любая хорошая презентация начинается не с дизайна, а со структуры. ИИ соберёт слайды за 30 секунд, но если структура слабая — слайды будут слабые.

**Что сделать:**

1. Сформулируйте тему — реальную или близкую к работе. Например:
   - «Итоги пилота автоматизации еженедельных отчётов за май»
   - «Анализ оттока клиентов в сегменте малого бизнеса»
   - «Предложение по запуску внутренней программы наставничества»
2. Заполните каркас структуры под одну из проверенных схем:

**Схема «Проблема → Решение → Результат» (для отчётов):**

```
1. Слайд-обложка: тема + спикер + дата
2. Контекст: что было до пилота, в цифрах
3. Гипотеза: что мы хотели проверить
4. Что сделали: 3 этапа, без технических деталей
5. Что получилось: 2–3 ключевые цифры
6. Что НЕ получилось: ограничения, риски
7. Что предлагаю дальше: 1 фраза, 1 решение для аудитории
```

**Схема «SCQA» (для рекомендаций):**

```
1. Situation — текущее положение дел
2. Complication — что сейчас не так
3. Question — какой вопрос мы должны решить
4. Answer — наша рекомендация
5. Доказательства (1–3 слайда с цифрами)
6. Что нужно от аудитории — конкретный запрос
```

3. Запишите для каждого слайда **одно ключевое сообщение** в формате полного предложения. Это потом станет заголовком слайда. Если предложение нельзя сформулировать — слайд лишний.

**На что обратить внимание:** правило 1 слайд = 1 мысль. Если на слайде хочется уместить три идеи — это три слайда. ИИ это понимает только если вы заранее разбили мысли.

## Шаг 2: Версия 1 — в Gamma (15 минут)

Gamma — самый быстрый путь от текста к красивой презентации с современным дизайном.

**Что сделать:**

1. Откройте `gamma.app`, войдите (15 бесплатных кредитов на старте)
2. Выберите «Generate → Presentation» и в первом окне напишите краткое описание задачи, а затем подсунете полный план:

```
Презентация по теме: [ваша тема из Шага 1]
Аудитория: [руководство компании / коллеги / клиенты]
Длительность: 5 минут (≈ 6–8 слайдов)
Тон: деловой, без воды
Стиль оформления: минимализм, корпоративный
```

3. На следующем шаге Gamma предложит автогенерацию плана — **замените её на свой план из Шага 1.** Скопируйте каждое ключевое сообщение как заголовок слайда
4. Запустите генерацию. Через ~30 секунд получите готовую презентацию
5. Пробегитесь по слайдам и сделайте 3–5 правок через кнопку «Edit with AI»:
   - «Замени иллюстрацию на более деловую»
   - «Сделай шрифт заголовков темнее»
   - «На слайде 5 добавь bullet-список из 3 пунктов»
6. Экспортируйте в PDF или поделитесь ссылкой

**На что обратить внимание:** Gamma хорошо работает на английском и хуже — на русском (особенно с типографикой). Если получились криво расставленные точки и тире — переключите шрифт на стандартный (Inter, Onest) и подровняйте вручную.

## Шаг 3: Версия 2 — в Kimi / GigaChat / другом инструменте (10 минут)

Сравнение нужно для того, чтобы понять, какой инструмент лучше под ваши задачи — не вообще, а **для ваших реальных кейсов.**

**Что сделать:**

1. Выберите второй инструмент:
   - **Kimi** (`kimi.moonshot.cn`) — китайская модель с генератором слайдов, хорошо понимает деловые контексты
   - **GigaChat** (`giga.chat`) — у Сбера есть «Презентации», работает на русском без оговорок
   - **Tome.app** — конкурент Gamma, шаблоны другие
   - **Beautiful.ai** — больше для сторителлинга, меньше для отчётов
2. Сгенерируйте презентацию по **тому же плану** из Шага 1
3. Сравните по таблице:

| Критерий | Gamma | Второй инструмент |
|---|---|---|
| Понял план без правок? | | |
| Качество русского текста | | |
| Уместность иллюстраций | | |
| Время от запроса до результата | | |
| Подходит ли стиль вашей компании? | | |
| Лимиты бесплатного тарифа | | |
| Можно ли экспортировать в PPTX (а не только PDF)? | | |

4. Сделайте вывод — что для каких задач:
   - Внутренние отчёты руководству → ?
   - Питч клиенту → ?
   - Учебные материалы для команды → ?

## Шаг 4 (опционально): Доводка под брендбук (5 минут)

ИИ-сгенерированные слайды редко проходят согласование «как есть» — корпоративный шаблон обычно строгий.

**Что сделать:**

1. Экспортируйте лучший вариант в PowerPoint (`.pptx`)
2. Откройте корпоративный шаблон-болванку (если есть)
3. Через `Файл → Темы → Сменить` примените корпоративные шрифты и цвета
4. Скорректируйте: логотип в шапке, нумерация страниц, копирайт в подвале

**На что обратить внимание:** идеальный путь для большинства компаний — «структура + черновой текст в ИИ → визуал в корпоративном шаблоне руками». Полностью автогенерированная презентация в большинстве случаев требует доводки, поэтому планируйте +30 минут на это.

---

## Итог дня

Через 30–45 минут у вас должно быть:
- Заполненный каркас структуры под реальную тему (6–8 слайдов с ключевыми сообщениями)
- Две презентации в двух разных инструментах по одному и тому же плану
- Таблица сравнения с выводом «когда что использовать»
- Один экспортированный файл, готовый к показу (PDF или PPTX)
