# AI-агенты и мультиагентные системы для разработчиков

- **Длительность:** 36 академических часов (3 недели)
- **Формат:** Пн–Чт лекция + практика · Пт самостоятельный проект
- **Аудитория:** Middle/Senior разработчики и бизнес руководители
- **Установленное ПО:** Python, Docker, Cursor, Ollama

### **Неделя 1: Инструменты, API, RAG, MCP**

**День 1 (Понедельник):**  
- **Тема:** AI IDE и промпт-инженерия. Cursor Rules, системные промпты, структурированный вывод, продвинутые паттерны Composer  
- **Практика:** настройка Cursor Rules, сравнение моделей на одном промпте, промпт-инжиниринг для production-кода

**День 2 (Вторник):**  
- **Тема:** Интеграция LLM через API. Роли, токены, стриминг, rate limits; GigaChat / YandexGPT как российская альтернатива  
- **Практика:** LLM-клиент с ролями и стримингом, retry на rate limits, подключение GigaChat / YandexGPT

**День 3 (Среда):**  
- **Тема:** RAG и векторные базы данных. Эмбеддинги, чанкинг, ChromaDB, сборка пайплайна  
- **Практика:** cosine similarity на эмбеддингах, индексация в Qdrant, retrieval с порогом score, сравнение стратегий chunking

**День 4 (Четверг):**  
- **Тема:** MCP. Подключение filesystem / GitHub / Brave Search / Postgres к Cursor; написание собственного MCP-сервера (mock-БД)  
- **Практика:** подключение готовых MCP-серверов в Cursor, HR-справочник с Resource

**День 5 (Пятница):**  
- **Тема:** Соло-проект: API-интеграция + базовый RAG-пайплайн  
- **Практика:** RAG-пайплайн поверх корпоративной документации, MCP-сервер `search_docs`, подключение к Cursor Agent

### **Неделя 2: Агенты: LangChain, LangGraph, HITL**

**День 6 (Понедельник):**  
- **Тема:** Advanced RAG: гибридный поиск и reranking. Dense + BM25 hybrid search; cross-encoder reranking (`sentence-transformers`); оценка качества RAG  
- **Практика:** BM25 vs dense на точных запросах, гибридный поиск через RRF, cross-encoder reranking, замер recall@3

**День 7 (Вторник):**  
- **Тема:** LangChain: первый AI-агент, отладка, мониторинг. Chains, Memory, Tools; Langfuse (self-hosted) для трейсинга  
- **Практика:** агенты на выбор: git commit по diff, анализатор логов, генератор README, аудитор .env; трейсинг в Langfuse

**День 8 (Среда):**  
- **Тема:** LangGraph: StateGraph, память, сложные сценарии  
- **Практика:** разбор тикетов через цепочку узлов, триаж инцидентов с conditional edges, конспект с циклом ревизии

**День 9 (Четверг):**  
- **Тема:** RAG + HITL, fallback-стратегии  
- **Практика:** HITL через interrupt(), confidence-based fallback, provider fallback + retry, трейсинг в LangSmith

**День 10 (Пятница):**  
- **Тема:** Выходной. День России  
- **Практика:** Самостоятельный формат опциональной практики  

---

### **Неделя 3: Мультиагентность, локальный LLM, продакшен**

**День 11 (Понедельник):**  
- **Тема:** Мультиагентные системы: Swarm и Supervisor  
- **Практика:** Supervisor для маршрутизации запросов, Swarm Developer ↔ QA с циклом ревизий, Handoff через Command

**День 12 (Вторник):**

**День 13 (Среда):**  
- **Тема:** Финальный проект: архитектурная сессия + начало реализации  
- **Практика:** проектирование AgentState и графа в Mermaid до написания кода, чеклист надёжности, stub-граф как точка старта

**День 14 (Четверг):**  
- **Тема:** Финальный проект: демонстрация результатов, часть 1
